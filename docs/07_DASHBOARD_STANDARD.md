# Dashboard Standard

## Purpose

The dashboard is the company's control center.

Everything a business owner needs should be available from one place.

The experience should feel simple, organized and professional.

---

# Mission

Business owners should never wonder where to manage something.

Every important action should be easy to find.

---

# Dashboard Goal

The dashboard exists to help businesses manage their presence on DinLinks efficiently.

Every action should save time, reduce complexity, and provide clarity.

---

# Dashboard Sections

The dashboard should contain:

1. Overview
2. Business Profile
3. Locations
4. Services
5. Gallery
6. Reviews
7. Analytics
8. Subscription
9. Account
10. Support

---

# Navigation

Navigation should always remain predictable.

Businesses should reach any major section in one or two clicks.

The current page should always be obvious.

---

# Overview

Display:

- Profile status
- Profile views
- Reviews
- Favorites
- Locations
- Recent activity

The overview should give a quick health check of the business.

---

# Business Profile

Manage:

- Basic information
- Description
- Story
- Contact
- Opening hours
- Areas served
- Company details

---

# Profile Completion

Businesses should always know how complete their profile is.

Encourage profile completion through clear progress indicators, not intrusive notifications.

A more complete profile should lead to greater trust.

---

# Locations

Allow businesses to:

- Add locations
- Edit locations
- Remove locations

Clearly show the primary location.

---

# Services

Businesses should be able to:

- Add services
- Edit services
- Remove services
- Set optional pricing

---

# Gallery

Manage:

- Logo
- Cover image
- Photo gallery

Images should be easy to reorder.

---

# Reviews

Businesses should:

- Read reviews
- Respond to reviews (future)
- Report abusive reviews

---

# Analytics

Show useful information only.

Examples:

- Profile views
- Search appearances
- Popular services
- Customer actions

Avoid vanity metrics.

---

# Notifications

Show only meaningful notifications.

Examples:

- New review
- Profile approved
- Subscription issue
- Missing profile information

Avoid unnecessary or distracting notifications.

---

# Subscription

Include:

- Current plan
- Billing history
- Invoices
- Payment method
- Upgrade
- Cancel subscription

Everything related to billing belongs here.

---

# Account

This section manages the owner's account.

Include:

- Personal information
- Email
- Password
- Language
- Notifications
- Security
- Delete account
- Two-factor authentication (future)
- Connected accounts (future)

Business settings and account settings must remain separate.

---

# Support

Provide:

- Help Center
- Contact support
- Report a problem
- Feature requests

---

# Dashboard Philosophy

The dashboard should simplify business management.

It should never overwhelm business owners with unnecessary options.

---

# Key Principle

The dashboard should feel like a professional business management tool, not an admin panel.

# DinLinks Constitution

## Purpose

This document is the permanent constitution for DinLinks.
It defines the core principles that guide every product, design, and business decision.

---

# Brand Identity

DinLinks is NOT:
- an AI product
- a startup landing page
- a SaaS dashboard
- a social network
- a futuristic neon interface

DinLinks IS:
- a trusted business directory
- professional
- timeless
- calm
- elegant
- Scandinavian
- premium through simplicity

The feeling should be:
"Reliable enough that every company wants to be listed."

---

# Design Principles

Always prefer:

- simplicity
- whitespace
- readability
- consistency
- balance

Never add visual noise.

---

# Components

Every component should feel:

- clean
- premium
- spacious

Avoid unnecessary borders.

Avoid unnecessary shadows.

---

# Copywriting

Placeholder text is temporary.

Every final text must:

- build trust
- sound professional
- sound human
- avoid marketing hype

---

# Decision Rule

If there are multiple design choices,
always choose the one that feels:

more timeless,
more trustworthy,
more premium.

Never optimize for trends.
Optimize for longevity.

---

# Decision Framework

Every product, design, engineering, and business decision must follow this priority order.

When two decisions conflict, the higher priority always wins.

1. User Trust
2. Accuracy
3. Simplicity
4. Consistency
5. Performance
6. Design
7. New Features

Definitions:

Performance = Runtime performance, responsiveness, and reliability of the product.

It does NOT refer to development speed.

Development speed should never compromise quality, trust, or accuracy.

---

# Decision Authority

The Decision Framework is the only ranked decision-making system in the DinLinks Playbook.

Whenever two principles conflict, contributors must follow this framework.

Other documents may define values, goals, metrics, or brand pillars.

They provide guidance but do not override the Decision Framework.

---

# Success Metric

A successful decision should improve at least one of the following outcomes:

- User Trust
- User Experience
- Information Quality
- Search Quality
- Business Value

If a change does not improve at least one of these areas, it should be reconsidered.

---

# Document Hierarchy

This document is the highest authority for DinLinks.

Other documents expand these principles.

They never replace or override them.

If any document conflicts with this constitution,
this constitution always wins.

---

# Non-Negotiable Rules

These rules complement the Decision Framework.
They do not replace or override it.

The following rules cannot be violated unless explicitly approved by the founder:

- User trust always comes before growth.
- Simplicity is preferred over complexity.
- Quality is preferred over speed.
- Features must solve real user problems.
- Every change must strengthen the DinLinks brand.
- Consistency is more important than creativity.

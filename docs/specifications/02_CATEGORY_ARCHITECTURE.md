# Category Architecture

## Status

Superseded

This document is no longer authoritative.

The official and sole source of truth for DinLinks taxonomy architecture is:

`docs/specifications/03_TAXONOMY_MASTER_LIST.md`

The Taxonomy Master List governs:

- Categories
- Subcategories
- hierarchy
- display names
- canonical slugs
- business assignment rules
- Homepage category behavior
- migration requirements
- validation rules

DinLinks uses exactly two taxonomy levels:

`Category → Subcategory`

No third taxonomy level is allowed.

Historical versions of this document remain available through Git history.

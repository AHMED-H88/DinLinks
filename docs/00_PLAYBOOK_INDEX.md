# DinLinks Playbook

## Purpose

This playbook defines how DinLinks is designed, built, and improved.

It is the single source of truth for product, design, user experience, and development decisions.

Every contributor should read this playbook before making changes.

---

# Core Principle

DinLinks is built around one goal:

Help people confidently choose the right business.

Every feature, interface, and decision should support that goal.

---

# Reading Order

Read the following chapters in order:

1. Constitution
2. Brand Identity
3. Copywriting Guide
4. UI Rules
5. Business Profile Standard
6. Search Experience
7. Dashboard Standard
8. SEO Standard
9. Performance Standard
10. Development Rules
11. Verification Standard
12. Localization Standard
13. Security & Privacy Standard

---

# Decision Hierarchy

If two documents appear to conflict:

1. Follow the Decision Framework defined in the Constitution.
2. The Constitution takes precedence.
3. Brand Identity defines product identity.
4. The relevant standard defines implementation details.

If uncertainty remains:

- Do not guess.
- Ask for clarification before implementation.

---

# Working Principles

Before implementing anything:

- Understand the purpose.
- Read the relevant chapter.
- Follow the standards.
- Keep consistency.
- Never sacrifice trust for convenience.

---

# Definition of Success

A successful change should:

- Improve user trust.
- Improve usability.
- Improve clarity.
- Improve consistency.
- Preserve the DinLinks identity.

---

# Final Principle

Do not build features because they are impressive.

Build features because they solve real problems.
